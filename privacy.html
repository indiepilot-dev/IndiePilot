Privacy Policy

Last updated: November 9, 2026

1. About IndiePilot

IndiePilot is a browser-based tool that helps indie game developers check localization CSV files.

2. CSV File Processing

CSV files selected in IndiePilot are processed locally in your web browser. The IndiePilot application does not upload your CSV file contents to an IndiePilot server.

3. Analysis Reports

Analysis reports are generated in your browser. You can download them to your own device. IndiePilot does not store these reports on an application server.

4. Accounts and Analytics

IndiePilot does not currently require user accounts. The application does not currently use its own analytics or advertising trackers.

5. Website Hosting

IndiePilot is hosted using GitHub Pages. GitHub may process technical information, such as IP addresses and access logs, when you visit this website. Please refer to GitHub's Privacy Statement for more information.

6. Changes to This Policy

This policy may be updated if IndiePilot's features or data practices change. Updates will be published on this page.

7. Your Choices

You can choose whether to select a CSV file and whether to download an analysis report. Avoid including unnecessary personal information in your CSV files.
